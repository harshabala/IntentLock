# IntentLock v1.5.1 Hardening Remediation Plan

> For agentic workers: use subagent-driven-development to execute this plan task by task.

Goal: remediate the reviewed MV3 runtime, intervention, privacy, correctness, accessibility, test, and release blockers without expanding V1 scope.

Architecture: keep the zero-dependency Chrome MV3 extension; convert the content-script dependency chain to ordered classic scripts; make the service worker authoritative for tab/session intervention state; add pure helpers and Node tests for privacy, retention, serialization, and packaging.

Tech stack: Chrome Manifest V3, plain JavaScript, Node built-in node:test, shell packaging, GitHub Actions.
