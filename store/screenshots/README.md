# Chrome Web Store screenshots

Required size: **1280x800** (Chrome Web Store listing screenshots).

A human must capture these from Chrome with IntentLock loaded unpacked. Do not invent or commit fake PNG screenshots of a running Chrome profile into this folder.

## Shot list (capture in this order)

1. **new tab intent form** — New tab page showing the session intent form (declare intent + optional time budget, Lock in).
2. **active session** — Active session view after locking in (timer / session hub).
3. **intervention** — Intervention overlay on a real site after drift (full-page lock; reflect or leave).
4. **settings** — Settings / options page showing the heuristics grid (intent category + strictness).
5. **settings** — Settings LLM section collapsed as optional (progressive disclosure closed; AI clearly secondary).

## Capture notes

- Load an unpacked build (`chrome://extensions` → Developer mode → Load unpacked).
- Use a clean window at 1280×800 viewport (or crop to 1280×800).
- Prefer real product UI over mockups; no fabricated browser chrome.
